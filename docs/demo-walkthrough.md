# Demo 演示脚本（Walkthrough）

> 一段约 90 秒的产品演示动线，面试 / 客户演示 / 朋友圈推广直接照做。
> 前提：已运行 `node start.js` 并执行过 `node scripts/seed-demo.js` 生成演示数据。

## 演示前准备（30 秒）

```bash
cd AI智能客服V3（node.js版）
node start.js                 # 启动全部服务
node scripts/seed-demo.js     # 生成 30 天演示数据（可选，已有数据可跳过）
```

## 常见问题速答（面试 QA）

**Q：为什么用两个服务（Node + Python）？**
A：按资源消耗模式拆分——Node 做 I/O 密集的 Web 接待（WebSocket/SSE/会话管理），Python 做 CPU 密集的 AI 计算（LangChain/DeepSeek 调用）。可独立扩缩容、故障隔离。

**Q：知识库怎么实现的？**
A：混合检索（Hybrid）——FTS5 全文检索 + 向量语义检索，RRF 融合排序。Embedding 用 DeepSeek/智谱 API，失败自动降级到本地哈希向量，保证演示/生产都可用。

**Q：AI 答不上来的问题怎么办？**
A：未答闭环——AI 兜底回答后自动记录到未答库，运营在管理后台补充答案一键入库，知识库持续进化。加上评价体系形成完整运营闭环。

**Q：安全方面做了什么？**
A：JWT 认证 + 角色分权（admin/agent/readonly）、敏感词实时检测 + 日志加密、Helmet 安全头、接口限流、前端全部 XSS 转义、访客 ID 服务端校验。
